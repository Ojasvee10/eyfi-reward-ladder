# EYFI Reward Ladder

An interactive and responsive reward ladder designed for the **EYFI Campus Ambassador Program**, built to make milestone progression engaging and visually appealing for college students.

## 🚀 Live Demo

https://eyfi-reward-ladder-po.vercel.app/

## 🛠️ Tech Stack

- React (Vite)
- Tailwind CSS
- Framer Motion
- Lucide React

## ✨ Features

- Interactive reward ladder with milestone-based progression
- Animated timeline and reward unlocks
- Glassmorphism-inspired UI
- Responsive design for desktop and mobile
- Toast notifications for unlocked rewards
- Smooth animations powered by Framer Motion

## 📝 Approach

The reward ladder was designed with a gamification-first approach to encourage engagement and clearly visualize user progression. Each milestone unlocks a new reward through smooth animations and interactive feedback, creating an experience that is intuitive, modern, and appealing to the target audience of college students.

The project emphasizes clean component architecture, responsive design, and reusable React components while maintaining a polished user experience.
